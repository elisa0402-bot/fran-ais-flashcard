# On y va · Windows 전용 단어장

브라우저 없이 별도 Windows 창에서 공부하는 프랑스어 뉴스 단어장입니다.

1. [Windows 앱 ZIP 받기](../downloads/OnYVa-Windows.zip)
2. ZIP을 **모두 압축 풀기** 합니다.
3. `설치하고 열기.vbs`를 두 번 누릅니다.
4. 다음부터는 바탕화면의 **프랑스어 뉴스 단어장** 아이콘을 엽니다.

실행 환경이 포함되어 있습니다. 인터넷 없이도 처음부터 89개 표현(2026-10-30 기준), 한국어 뜻과 예문을 볼 수 있습니다. 인터넷에 연결하면 저장소의 `news/data.json`에서 새 어휘를 합칩니다. 개인 진도와 메모는 컴퓨터에만 저장합니다.

프랑스어→한국어를 먼저 익히고, 기억한 표현은 한국어→프랑스어로 복습합니다. ‘설정과 백업’에서 JSON 백업과 복원, CSV 단어 추가, Anki TSV 내보내기를 사용할 수 있습니다. 웹 학습 진도는 웹에서 백업한 파일을 새 앱에서 불러오세요.

앱은 사용자별 `OnYVaCarnet` 폴더에 설치됩니다. 단어와 진도는 그 안의 `Data/progress.json`에 저장합니다. Windows의 앱 폴더 리디렉션이 있는 경우에도 설치 파일의 실제 경로를 사용합니다.

소스는 `OnYVaCarnet.pyw`입니다. Python/Tk 기반이며 웹 브라우저나 WebView를 사용하지 않습니다. 배포 ZIP에는 Python, Tcl/Tk 실행 환경과 해당 라이선스가 포함됩니다.
